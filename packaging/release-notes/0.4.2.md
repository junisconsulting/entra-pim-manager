# Entra PIM Manager 0.4.2

Entra China (21Vianet) is genuinely usable now: one App Registration per cloud, picked automatically per account.

## New

- **An App Registration per cloud.** Settings → App Registration now has a row for Entra Global and one for Entra China (21Vianet). Microsoft's national clouds are physically isolated instances of Entra — an App Registration exists in exactly one of them, and "multitenant" means every tenant *in that cloud*. The China option shipped since 0.1.0 could therefore never work: it sent the Global client id to `login.partner.microsoftonline.cn`, where that application simply does not exist. Register a second app at `portal.azure.cn`, paste its client id, and Global and China accounts work side by side — each enrollment routes its own sign-in, token cache and Graph endpoint. See `docs/app-registration-setup.md` §7.
- **The cloud picker only offers clouds you have configured.** With a single App Registration it disappears entirely, so the common single-cloud setup is one field simpler than before.
- **Verification is now per cloud.** A successful Global sign-in says nothing about the China registration, so each one earns its own green badge.

## Fixed

- **Choosing "Entra China" without naming a tenant no longer signs you into Global.** The blank-tenant path ignored the cloud selection and enrolled the account against the Global authority without a word. Any account added this way is recorded in the wrong cloud — remove it in Settings and add it again.
- **A client id that doesn't exist in the selected cloud gets a real explanation** instead of a raw `AADSTS700016`, as does a cloud with no registration configured at all.
- **A long tenant name no longer runs over the countdown.** In an active row the tenant and role kind now shorten with an ellipsis instead of overflowing into the time remaining — most visible with non-Latin tenant names, which are wider per character. The countdown itself moved out of that row: the remaining time reads as plain text next to the stop button, and the share of the activation window still ahead is now a thin bar across the bottom of the card, which is easier to judge at a glance than the old ring.

## Notes

- **Upgrading in place?** Nothing to re-enter. Your existing `ClientId` is read as the Global registration, and your accounts are untouched. The only visible change is the App Registration badge in Settings, which drops back to "configured, not verified" once and goes green again on the next sign-in.
- The China path was verified end to end against a real 21Vianet tenant — eligibilities list, and activation and deactivation both work. Microsoft still does not guarantee feature parity across national clouds, so confirm it in your own tenant before relying on it in production.
