# Entra PIM Manager 0.6.1

A small release about a single window: the update prompt now says who it is and what
"restart" means.

## Fixed

- **The update prompt names the application and both versions.** The prompt appears in the
  bottom-right corner over whatever you happen to be working in, and until now it only said
  *"Version 0.6.1 available"* — with no product name anywhere, because the window has no
  title bar. Several people asked which program was talking to them. It now shows
  **Entra PIM Manager** as its heading, with the version you are running and the version on
  offer directly beneath it (for example *"Version 0.6.0 → 0.6.1"*), through every step of
  the update.
- **The restart wording no longer sounds like a Windows restart.** After a download the
  prompt asked you to "restart now", which read to some as *restart the computer*. It now
  states plainly that only Entra PIM Manager restarts, that Windows is not affected and no
  other application is closed, and the button says **Restart app now**. Declining still
  applies the update the next time you start Entra PIM Manager.

## Notes

- Wording and layout only — the update mechanism itself is unchanged, including the
  72-hour release-age wait introduced in 0.6.0.
- Upgrading in place: nothing to re-enter, no new permissions, no admin consent.
