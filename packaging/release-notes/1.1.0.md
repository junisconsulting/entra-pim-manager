# Entra PIM Manager 1.1.0

The app now tells you when a role activates without a fresh sign-in, and it no longer loses your
saved data or closes when something goes wrong.

## New

- **The activation panel says when a role activates without asking you to sign in again.** Unless
  a role requires a Conditional Access authentication context, the sign-in you did earlier is
  enough to activate it. The panel now says so for every such role and links to a short guide:
  [A fresh sign-in for every activation](https://github.com/junisconsulting/entra-pim-manager/blob/main/docs/fresh-sign-in.md).
  An admin sets it up once per tenant, and with a passkey in Windows Hello the prompt is a glance
  or a touch. For Azure resource roles whose settings the app cannot read, it says nothing.
- **An unexpected error no longer closes the app.** It shows an "Unexpected error" notification
  and keeps running, so the tray icon and the expiry warning stay. The cause is in the log.

## Fixed

- **Saved data survives a file that is briefly locked**, for example by a virus scanner at logon.
  Saved justifications, saved scope sets, your settings and pins, and the list of added accounts
  could be replaced by an almost empty file. Now a save that cannot read the file first fails
  instead, and the app tries again for a moment before it gives up.
- **Saving or removing a saved justification and copying the network report** no longer close the
  app when they fail.
- **The install script and the Intune package build** accept a path to `Setup.exe` that contains
  square brackets.
