# Entra PIM Manager 0.4.1

Honest status signals: you can see when your setup is confirmed, and the tray icon no longer cries wolf.

## New

- **App Registration now shows whether it actually works.** Settings tells you where you stand — not configured, configured but unverified, or verified. The green badge appears only once an account has successfully signed in, because that is the moment the ClientId, public client flows, redirect URI and admin consent are all proven at once. A saved GUID alone proves none of them. Once verified, the section collapses out of the way.

## Fixed

- **The tray icon no longer turns red while a role is still active.** A role approaching expiry now shows amber; red is reserved for "you are not signed in". The resting state — signed in, nothing active — moved to a neutral grey, so amber means exactly one thing: act now. The icons also ship in every size Windows asks for, so they stay sharp at 125 % and 150 % display scaling.
- **Device-code sign-in gives a usable error message.** A role protected by a Conditional Access authentication context cannot be activated with a device-code account, yet the old message asked the user to "try again" — advice that could never work. It now names the cause and the way out. Accounts signed in this way are marked "Device code" in Settings, since the limitation is otherwise invisible.

## Notes

- If a role protected by an authentication context refuses to activate, check Settings → Accounts for a "Device code" mark on the account. Removing it and signing in again through the standard sign-in resolves it.
