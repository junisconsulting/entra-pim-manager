# Entra PIM Manager 1.3.0

Admins can now turn off junis-hosted on managed devices, while users keep adding tenants
themselves.

## New

- **Admins can turn off junis-hosted.** For organizations that require their own App
  Registration: a machine policy (`DisableJunisHosted` = 1 under
  `HKLM\SOFTWARE\Policies\junis\Entra-PIM-Manager`) makes the app ask only for a client id when a
  tenant is added or edited, and the tenant cards no longer say junis-hosted or self-hosted. Unlike
  the tenant lock, users can still add tenants. Rollouts on such devices pass `-ClientId` to the
  install script:
  [Turn off junis-hosted](https://github.com/junisconsulting/entra-pim-manager/blob/main/docs/unattended-deployment.md#turn-off-junis-hosted).
