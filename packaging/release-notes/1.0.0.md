# Entra PIM Manager 1.0.0

Ready for production: an App Registration junis runs for you, and releases signed by junis GmbH.

## New

- **junis-hosted: use Entra PIM Manager without an App Registration of your own.** Choose
  **junis-hosted** when you add a tenant under **Settings → Tenants**, or leave out `-ClientId` in
  `install-entra-pim-manager.ps1`. An admin of your tenant consents once, either in the app's own
  sign-in window, with **Consent on behalf of your organization** ticked, or through the consent
  link the app shows. After that, everyone in the tenant can sign in. How junis runs and protects
  the registration, its client id and its eight delegated permissions are in
  [SECURITY.md](https://github.com/junisconsulting/entra-pim-manager/blob/main/SECURITY.md#the-junis-hosted-app-registration).
  Your own App Registration keeps working as before, and Entra China still needs it.
- **Releases are signed by junis GmbH.** Windows now names junis GmbH as the publisher, and
  Defender's "advanced protection against ransomware" rule no longer blocks a fresh release.
  SmartScreen and the "prevalence, age, or trusted list" rule still judge a brand-new release by
  its reputation, so updates keep arriving 72 hours after a release.
- **Uninstalling also signs your accounts out of Windows.** Their sign-ins used to stay with
  Windows' token broker after the app was gone. An account you added to Windows itself stays there.

## Fixed

- **A tenant without a PIM licence says so.** Instead of an empty list it reads "PIM is not set up
  in this tenant, usually because it has no Microsoft Entra ID P2 or Governance license."
- **Missing Azure roles name the likely cause.** When Windows refuses the background sign-in for
  Azure, the tenant says that admin consent for Azure is probably missing, or that a Conditional
  Access policy for Azure management wants a stronger sign-in, instead of "see the log file".
- **The account you used last is selected again when the app starts.**
- **A settings change no longer gets lost.** Two changes saved at the same moment, such as the
  last-used account and a pin, could overwrite each other.
- **`Get-Help` shows the deployment scripts' help again.**
