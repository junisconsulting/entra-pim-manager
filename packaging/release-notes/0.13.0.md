# Entra PIM Manager 0.13.0

Your organization's logo in the panel, and a calmer header.

## New

- **Your organization's logo at the top right of the panel.** Set it under **Settings →
  APPEARANCE → Logo**: **Choose…** takes a PNG, **Remove** takes it away again. A rollout can
  bring it instead: `install-entra-pim-manager.ps1 -LogoPath <file.png>` places it on every
  endpoint, and `packaging/intune/build.ps1 -LogoPath <file.png>` packs it into an Intune package of
  your own — the package attached to each release stays tenant-neutral and carries no logo. It
  looks best as a tightly cropped PNG with a transparent background, about 96 px tall and no wider
  than about 4:1, in a version that reads on both the light and the dark theme. Details:
  [docs/unattended-deployment.md](https://github.com/junisconsulting/entra-pim-manager/blob/main/docs/unattended-deployment.md#your-organizations-logo).

## Changed

- **Settings moved to the bottom right, refresh to the list.** The header now holds only the app
  name, your role counts and, if there is one, your organization's logo. **⚙** sits alone in the
  right corner of the footer, which stays in view however far you scroll. **⟳** sits next to
  ELIGIBILITIES, the list it reloads — rarely needed, since the list keeps itself current. Both are
  still in the tray icon's right-click menu.
